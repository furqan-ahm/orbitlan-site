Windows + Android checklist

Taking a laptop and Android phone to China?

Set up both devices before you leave. It takes less time than trying to recover installers, passwords, and permissions after something stops working.

Written by me · Published October 5, 2026 · About 6 minutes

Disclosure: I build OrbitVPN for Windows and Android. This checklist still applies if you choose another provider. There are no affiliate links here.

A phone and a laptop fail in different ways. Android may stop a background app to save battery. Windows may need administrator access to create its network adapter. An account may allow one device when you assumed it covered two. It is much easier to catch all of that before the trip.

First, check whether one account covers both devices

“Supports Windows and Android” does not necessarily mean “lets me use both at the same time.” Look for the simultaneous-device limit. If the plan is limited to one device, signing in on the laptop may disconnect or sign out the phone.

Also check how device replacement works. A good setup should give you a clear way to remove an old phone or ask support to reset it without sharing your password.

Android setup before China

  1. Get the app from the provider’s real download page. If it is an APK, verify that the filename, version, and checksum match what the provider publishes.
  2. Approve the VPN permission. Android shows a system prompt the first time an app creates a VPN connection.
  3. Check battery settings. If the connection dies when the screen locks, allow the VPN app to run in the background and remove aggressive battery restrictions.
  4. Switch from Wi-Fi to mobile data. Confirm the app recovers instead of leaving the phone with a dead route.
  5. Disconnect from inside the app. Make sure normal internet access returns without force-closing the process or restarting the phone.

Windows setup before China

  1. Download and extract the real package. Do not run an executable while it is still buried inside a ZIP file.
  2. Allow the required administrator step. VPN software normally needs elevated access to create or configure its network adapter.
  3. Check the publisher warning. Smaller beta software may be unsigned, but the provider should say so clearly and publish a checksum.
  4. Test minimize and close separately. Know whether minimizing leaves the VPN running and whether closing the window disconnects it.
  5. Reconnect after changing Wi-Fi. A useful client should notice the network change and recover or give you a clear action.

Keep a small offline recovery folder

I would keep one folder with the Android APK, Windows package, published checksum, support contact, and a short setup note. Put it somewhere available to both devices. Do not store your password in a plain text file next to the installer.

If you are a student, include the offline details for your university portal, class schedule, and any multi-factor recovery codes you are allowed to save. The goal is not to collect everything. It is to avoid one inaccessible inbox locking you out of everything else.

Do one final real-world test

Connect the phone, lock it for ten minutes, and then open a site. Connect the laptop, minimize the app, and use it normally for a while. Try a short voice or video call if calls matter to you. Finally, disconnect both and make sure ordinary internet access comes back.

That test is still not a guarantee for every network in China, but it tells you much more than a green icon and a single speed test.

Check current rules too

China controls internet access and requires VPN services to be licensed. Read current official guidance and follow local law. This setup checklist is not legal advice.
